# Project Rules

## Communication

- Respond in Korean.
- For complex tasks, present a checklist before implementation.
- Keep completion messages concise.

## Validation

- Run `yarn lint` after code changes.
- Run the smallest meaningful validation.
- If tests already exist, update them.
- Do not introduce a new test framework.

## Safety

- Do not commit or push unless requested.
- Do not modify unrelated files.
- Preserve the existing architecture.
